# Privacy

This page covers the **OpenFlowsheet documentation website** you are reading.

These pages are static and are served by GitHub Pages from the public
[`openflowsheet`](https://github.com/computational-chemical-engineering/openflowsheet) repository.

* We set **no cookies** and run **no analytics**. There is no tracking script on this site.
* We do not collect, store or process any personal data from visitors.
* GitHub serves the files and may log request data (including IP addresses) for its own
  operational and security purposes, under
  [GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).
  We neither receive nor have access to those logs.
* The pages load no web fonts, embedded media or external scripts. The one third-party resource
  is the version badge on the home page, an image served by [shields.io](https://shields.io), whose
  request reaches that service.

The OpenFlowsheet software itself sends nothing anywhere: it runs on your machine, and its HTTP and
MCP servers bind to your own computer unless you configure them otherwise.

Questions about this page: open an issue at
<https://github.com/computational-chemical-engineering/openflowsheet/issues>.

Any change to this page is committed to the public repository, so its history is visible in the
file's git log.
