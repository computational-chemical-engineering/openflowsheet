# Design

The design records live in the repository and are not rendered here, so there is one copy of each.
They are the normative texts behind this documentation.

| Record | What it is |
| --- | --- |
| [Blueprint v3.1](https://github.com/computational-chemical-engineering/openflowsheet/blob/main/docs/blueprint-v3.1.md) | the architectural authority |
| [Implementation plan](https://github.com/computational-chemical-engineering/openflowsheet/blob/main/docs/implementation-plan.md) | work packages, order, acceptance evidence and gates |
| [Architecture decision records](https://github.com/computational-chemical-engineering/openflowsheet/tree/main/docs/adr) | the normative decisions — for example ADR 0001 (units, state, zero flow, signs), ADR 0007 (certificates and reproducibility), ADR 0019 (the application contract), ADR 0050 and 0051 (the selectable bases and the pure-fluid units) |
| [Decision register](https://github.com/computational-chemical-engineering/openflowsheet/blob/main/docs/decision-register.md) | what was chosen, what was rejected, and why — indexed by the question each decision answers |
| [Derivations](https://github.com/computational-chemical-engineering/openflowsheet/tree/main/docs/derivations) | the specifications the code is tested against |
| [Frozen interfaces](https://github.com/computational-chemical-engineering/openflowsheet/blob/main/docs/interfaces-frozen.md) | the protocols and schemas that change only by ADR |
| [Support matrix](https://github.com/computational-chemical-engineering/openflowsheet/blob/main/docs/support-matrix.md) | the supported envelope with its evidence |
| [Schemas](https://github.com/computational-chemical-engineering/openflowsheet/tree/main/schemas) | the JSON Schemas of every document |
| [Evidence manifests](https://github.com/computational-chemical-engineering/openflowsheet/tree/main/evidence) | per work package: what was tested, at which commit, with which result |
