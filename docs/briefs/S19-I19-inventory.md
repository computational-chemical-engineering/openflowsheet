## Definitions (from the brief)

- A **re-export** is a module-level name in `src/openflowsheet/**` bound by an import (any depth of module-level
  if/try/with, TYPE_CHECKING included) rather than defined there. It is **added by S17 or S19** when the module did
  not bind it by import at S17's base 1fd6826b (a module absent there counts as added), or when S17/S19 added its
  re-export marker (an `X as X` alias or an `__all__` entry; this is how the sizing A8 aliases count).
- An **importer through the old path** is a file in src, tests, scripts, benchmarks or examples that takes the name
  from the re-exporting module: a from-import at any depth (relative resolved), `m.N` with `m` bound to the module, a
  call `f(m, "N", ...)`, a dotted string `"openflowsheet.<module>.N"`, or a factory reference
  `{"module": ..., "attribute": "N"}`. A patch (setattr, assignment, dotted string) of a name the module itself reads
  is a **live patch point**: listed, not counted as an importer (it patches where the name is used).
- "added in" is the oldest commit after 1fd6826b that `git log -S<name>` finds on the module's path; S17 if it is an
  ancestor of S19's CB d90b498f, else S19.
