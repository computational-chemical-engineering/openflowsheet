Brief: `docs/briefs/DOC-site.md`. Branch `wp/DOC` from `main` `6c382a90`. Build lane; no design-lane question is
numerics-changing. Each choice below is isolated so that a revert undoes it.

## Decisions

- DECISION D1: site generator → MkDocs + Material + mkdocstrings (Python handler), source `docs-site/`, `mkdocs.yml` at
  the root, output `site/` (git-ignored). Alternative: Sphinx + autodoc. Reversible by: replacing `mkdocs.yml`,
  `docs-site/` and `site.yml`. (Orchestrator's choice, Peclet's layout.)
- DECISION D2: cost estimation and LCA → **not documented in this branch**. E01 (`src/openflowsheet/assessment/`) is not
  on `main` at `6c382a90`; it is in its merge gate on `wp/E01`/`wp/E01b`, and its page and example would document code
  this branch does not have (and `mkdocs build --strict` would fail on the API page). Alternative: base `wp/DOC` on
  `wp/E01b` (ties this merge to E01's). Reversible by: adding `docs-site/guide/assessment.md`, an API page and a
  notebook once E01 is on `main` (handoff item 1).
- DECISION D3: `semantic_role` of `thermal.turbine` and `thermal.compressor` in the examples → `pump`, stated in the
  notebook as "the nearest pressure-changer role; descriptive, not read by the binder". The frozen `process-revision`
  schema's enum has no turbine/compressor/other, and the committed S11 cases (`benchmarks/s11/thermal`, `gp`) use
  `other`, which the application's validation refuses (`SCHEMA-01`). Alternative: an ADR adding roles (design lane).
  Reversible by: editing two notebooks. **Escalated** as question Q1 below.
- DECISION D4: the notebook test executes code cells with a stdlib driver in a subprocess (`tests/test_doc_examples.py`),
  not nbclient. Alternative: add nbclient + ipykernel to the `dev` extra and `requirements.lock` (moves a registered
  identity, R-140, and the licence inventory). The site build executes the same notebooks with mkdocs-jupyter
  (nbclient) in CI. Reversible by: swapping the driver for nbclient once the dev lock carries it.
- DECISION D5: `requirements-docs.txt` → the hash-pinned **increment over `requirements.lock`** (the pattern of
  `requirements-coolprop.lock`), installed `--no-deps --require-hashes`; packages the lock already pins are dropped so
  the two files never disagree. Generated by `uv pip compile` with `-c requirements.lock --generate-hashes`; the recipe is
  in the file's header. Alternative: the full closure with duplicate pins. Reversible by: regenerating the file.
- DECISION D6: the install page lists the extras `pyproject.toml` declares (`server`, `coolprop`, `nlp`, `dev`). The
  brief named an `lca` extra; there is none on `main` (E01 not merged). Reversible by: one table row.
- DECISION D7: the Wilson records → documented as read from a **source checkout** (today's code, `wilson_ig.load_records`,
  R-706). Frank decided on 2026-10-29 that 0.3.0 ships them (Q-F3); that packaging change is not on `main` yet. The
  property-basis page says so in one sentence, to be updated when the change lands (handoff item 2).
