## Context

The plan asks T08 to select the v0.2 chemistry on a scored dossier. The OpenIDAES-450 audit (`origin/study/openidaes450`) flagged IDAES cases as candidate references. Reading the released cases (measured 2026-09-29, T08 spec §7.3): the methanol loop case is ideal-property with a stoichiometric reactor; the ethylene-glycol cases are once-through, liquid-only and ideal; HDA and SMR cases exist but need no clearly necessary nonideal route. Separately, a packed-bed ammonia synthesis reactor model built by Frank's group on `pymrm` (MIT, maintained by E.A.J.F. Peters) exists in the group's repository, with a 1D and a 2D solver, a kinetics class with fugacity coefficients, a property database, regression tests and an experimental conversion dataset.

## Decision (proposed)

1. **Chemistry:** ammonia synthesis, N₂ + 3H₂ ⇌ 2NH₃, over the catalyst the group's kinetics describe; components H₂, N₂, NH₃ plus one or two inerts (Ar, CH₄) so that the purge is meaningful.
2. **Journey:** the synthesis loop — fresh feed, mixer with recycle, preheater, reactor, cooler, high-pressure flash condensing NH₃, purge splitter, recycle — at fixed topology; a recycle compressor or a zero-pressure-drop loop convention is M01's decision.
3. **Reactor for M01:** the group's 1D PyMRM packed-bed model in a conventional (no-membrane) configuration, pinned by repository commit and `pymrm` version; if the model cannot run without a membrane, M01 writes a plain packed bed in PyMRM from the same kinetics. Executed out of process (M02).
4. **Nonideal property route (W22):** a cubic equation of state (Peng–Robinson, or SRK if the kinetics' fugacity correlations argue for it), both phases, with binary interaction parameters from the literature; conformance against an independent implementation and published high-pressure VLE data.
5. **Independent reference:** IDAES 2.13 (modular cubic EOS, a custom rate expression) for the loop skeleton, first with an equilibrium reactor; DWSIM as a second tool where it helps, noting .NET 8's end of life on 2026-11-10. The group's experimental dataset is the kinetics' empirical anchor — validation evidence, kept separate from numerical verification.
6. **Continuous design decision:** the reactor inlet temperature (an equilibrium model favours ever-lower temperature for this exothermic reaction; a kinetic model gives an interior optimum), with the purge fraction as the alternative.

## Alternatives considered

- **Methanol synthesis loop (runner-up, total 11 against 12).** Rights-cleared IDAES loop cases exist and overlap OpenIDAES for W27; the methanol–water NRTL case feeds v0.3's columns. Not first: no group model found (S1 = 0), and the IDAES cases reference neither the kinetics nor a nonideal route, so the scientific comparison would still be built; two independent reactions and two nonideal needs (gas EOS, liquid activity) make M01 larger. **It becomes first if C1's rights or reactor route fail (H5, H1), or if Frank names a group methanol model.**
- **Ethylene glycol (11).** The best fidelity story (DEG selectivity against back-mixing) and the cheapest nonideal route (NRTL), but no native recycle within v0.2's units and an IDAES case with no selectivity.
- **HDA (10)** and **steam methane reforming (5).** A nonideal route not clearly needed; little that a distributed PyMRM reactor adds.

## Consequences

- M01 pins the reactor (commit, `pymrm` version, configuration) and the property route, and derives the boundary mapping against ADR 0001's state and ADR 0011's formation datum; the elemental balance (N, H) is checked for the first time.
- M01 adds a cubic-EOS provider: cubic root selection is new phase logic and needs its own design-lane derivation and adversarial cases.
- Parameter records carry `rights` from their first commit (ComponentRecord already requires it); the group's code is used by reference, never vendored, unless Frank licenses it otherwise.

## Proposed revision 1 (2026-10-01, T08 release spec Amendment R3 8) — the reactor pin and the property method for C1

**Status:** Proposed, design lane, pending Frank's F3 like the rest of this ADR; register R-143. Decisions 1, 2, 5 and 6 are unchanged.

**Decision 3, revised (the pin).** The reactor is the group's release `ammonia_synthesis_reactor` (MIT; Zenodo concept DOI 10.5281/zenodo.22811033), pinned at **`main` @ `6089593464fc9bc2c0a0cb58e30ad5433ece6332`**, the commit T08.A61 measured; tag `v1.1.0` (`d78fbfb`) differs in `CITATION.cff`, `README.md` and `src/reactor/archive.py` and was not run. The 1D model runs without a membrane (all permeance pre-factors zero): non-isothermal it converges from the group's cold start; isothermal it converges from `dt_init` 1e-2 but not from 1e-6 or 1e-3 (`benchmarks/t08/v19/c1-reactor.json`). The fallback "M01 writes a plain packed bed" is therefore not needed; M01 registers the start it uses.

**Decision 4, revised (the property method).** Peng–Robinson with **H₂, N₂, Ar and CH₄ declared vapour-only** (the liquid is NH₃ alone; IDAES's `HC_PR` convention), in M01's provider and in the IDAES reference alike. IDAES 2.13 represents the loop skeleton with this method; with every component in both phases its flash ends on the trivial solution (`benchmarks/t08/v19/c1-idaes.json`). Binary interaction parameters stay a dossier item (k_ij = 0 today, no source). Cubic root selection per phase remains M01's derivation item; trivial-solution avoidance for a multicomponent liquid is not needed. **v0.2 limitation:** no dissolved light gases — the purge is the inerts' only exit, and NH₃ product purity and dissolved-gas losses are not represented; their effect on the inlet-temperature decision is not measured. Full VLE with dissolved gases is a later item with its own reference.

**Also recorded (R-143).** T08.A61 is the group's pytest suite at the pin (72 collected, 69 passed, 3 skipped by the suite's own guards on unshipped data, counted not reproduced) and one converged non-isothermal solve; a comparison with the published 4TU results is M01's. H2 is met; the K_NH₃ enthalpy term (7000 cal/mol in the code, 29 228 J/mol in Gargiulo et al. 2025 Table 1) is an M01 pin item, read from Rossetti et al. 2006, pending Frank's check.

**Rejected.** Full PR VLE as the v0.2 method (no acquired tool represents it, so no independent reference); the tag commit as the pin (evidence is about the commit measured, R-121).
