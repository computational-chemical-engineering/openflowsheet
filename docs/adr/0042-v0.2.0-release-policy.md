# ADR 0042 — The 0.2.0 release policy: `v0.2-gate-v1` claims all seventeen gates, each judged at its own candidate, with per-release acceptance of failures

**Status:** Proposed, 2026-10-16. Accepted when Frank's answers to the four items of the table below are recorded and
M07's manifest is `tested` for M07.A30–A38.
**Author:** design lane (`specifier`), M07.
**Normative text:** `docs/derivations/M07-spec.md` §7–§10; registration `gate` member.
**Builds on:** ADR 0028 and `docs/derivations/V02-alpha-release-spec.md` (§4, §7, §8; Amendments 1–4), ADR 0021 D3, D5.
**Register:** R-338, R-339.

## Decision

- **D1 — Claim set.** `v0.2-gate-v1` covers `0.2.0`, `0.2.0bN`, `0.2.0rcN` and claims V11–V20 and W21–W27; nothing is
  unclaimed (spec §7.1–§7.2).
- **D2 — Judgement.** The alpha spec §4 rules apply with this ADR in place of ADR 0028: `BLOCKED` blocks the tag; a
  `FAIL` is releasable only if its clause is in the D3 table below with Frank's acceptance dated on or after the 0.2.0
  verdict's `Judged` date; evidence about another commit reaches C only through the RC job.
- **D3 — Accepted failures for 0.2.0** (table; filled by Frank after the verdict; empty means none accepted).
- **D4 — Script.** One registry entry beside `v0.2-alpha-gate-v1`; the only structural change is a per-set clause
  grammar, leaving the alpha entry's behaviour byte-identical.
- **D5 — The tag is Frank's** (ADR 0021 D5).

The two tables' column layout follows ADR 0028's, which the gate script parses (alpha spec §7.2 item 3, §7.3
item 11); WO-6 conforms the layout without changing the content.

## Alternatives rejected

- *Leave W24 unclaimed while M03 N1 is open.* Departs from plan §4.4's W21–W27 gate; kept as Frank's alternative
  (a `v0.2-gate-v2` by amending this ADR).
- *Carry the alpha's acceptances.* An acceptance dated before the evidence is a waiver (ADR 0021).
- *Widen the module clause grammar.* Changes how the alpha reads stray W23–W27 tokens.

## Affected requirements

V11–V20, W21–W27; R-151 (tree records); RELEASING (a 0.2.x release needs `scripts/v0_2_gate.py` and its own RC).

## Migration impact

`scripts/v0_2_gate.py` gains a field and an entry; the alpha's tests pass unchanged.

## Acceptance evidence

M07.A30–A38 (default gate), M07.A40–A43 and A60–A62 at C.
