# C10 — build decisions (IAPWS-95)

Append-only. One line per choice: `DECISION: <question> → <choice>. Alternative: <x>. Reversible by: <how>.`

Specifier, 2026-10-22 (design lane; first pass, stopped at the context cap before the spec was written; see `docs/briefs/C10-handoff.md`).

- DECISION: package id for the manifest → `S05` (`evidence/S05/`, checks `S05.Axx`; branch stays `wp/C10` until the build lane renames it, as L01→S04 under R-565). Alternative: keep `C10` (a C-item, so no manifest under R-565). Reversible by: renaming before the first manifest is written.
- DECISION: independent expectations → iapws.org is refused by the session proxy (CONNECT 403, 2026-10-22), so R6-95(2018) Tables 6–8 cannot be read. Registered values come from an mpmath 50-digit generator (`docs/derivations/scripts/s05_reference.py`) over coefficients transcribed from CoolProp 8.0.0 (`get_fluid_param_string('Water','JSON')`, 76 556 chars, SHA-256 `a10a0da6c55e623cccc1f56a70cb348c772d8fc1710a6a142b459abb0dec4586`). Each value is admitted only when CoolProp 8.0.0 and `iapws` 1.5.5 (PyPI; `iapws/iapws95.py` SHA-256 `89edb7c0e3b77533319d253819cdb4c1da50775d2e7b324249574607d6790520`) both agree with it. Comparison with the printed tables is an open *needs a fact* item. Alternative: wait for the release PDF. Reversible by: adding release-table assertions once the tables have been read.
- DECISION: generator layout → `s05_reference.py` (project venv, mpmath only, reads the committed coefficient JSON, `--check`) plus `s05_crosscheck.py` (runs only in a scratch venv with CoolProp 8.0.0 and iapws 1.5.5; writes `s05_crosscheck.json` with versions and hashes, and its own `--check`). `s05_reference.py` refuses to emit if the committed cross-check disagrees beyond its tolerances, so the claim that the implementations agree can be executed in the project venv. Alternative: one script that imports CoolProp, which would put CoolProp in the project venv (forbidden). Reversible by: merging the two scripts if the packages are ever vendored.
- DECISION: coefficient set → the R6-95 revised release (2016/2018). Its ideal-gas coefficients are n°1 = −8.3204464837497 and n°2 = 6.6832105275932, and both sources carry these values. R = 0.46151805 kJ/(kg·K) and M = 18.015268 g/mol, so the molar R is 8.314371357587 J/(mol·K): the IAPWS value, not CODATA's 8.31446261815324. Molar quantities are the specific values × M. Alternative: CODATA R, which departs from the formulation. Reversible by: a new provider id.
- DECISION: reference convention → a new `IAPWS95-ref-v1`, the formulation's own datum (u = 0 and s = 0 for the saturated liquid at the triple point, 273.16 K). It is not a formation datum and not in ADR 0011 D2's reaction-consistent set. Alternative: shift so that the ideal gas at 298.15 K has h = Δ_fH°. That was rejected because pure water has no reaction and ADR 0001 D5.2 already forbids mixing streams across providers. Reversible by: a later ADR adding the offset. FINDING (not written by C10): when the ADR is accepted, ADR 0001 D5's list and `interfaces-frozen.md` need a new line, as ADR 0026 did for `PR-C1-ref-v1`.
- DECISION: domain → T ∈ [273.16 K, 1273.15 K] and P ∈ [1.0e2 Pa, 1.0e8 Pa]. Leaving it gives `out_of_domain`. Ice is excluded because T ≥ T_t and P ≤ 100 MPa < 209.9 MPa (ice Ih/III). Alternative: the formulation's full range up to 1 GPa. Reversible by: widening the box, with new assertions.
- DECISION: phase rule →
  - T ≥ T_c: the single fluid is reported as VAPOR, and a LIQUID request is refused `phase_not_stable`.
  - T ≤ T_σ,max = 647.0 K: with s = ln(P/p_σ(T)), LIQUID is answered iff s ≥ −ε_σ and VAPOR iff s ≤ +ε_σ, with ε_σ = 1e-6. Inside the band both phases are answered, each on its own branch root, so a round trip through T_σ(P) works.
  - T ∈ (647.0 K, T_c): P ≥ p_c gives LIQUID and P < 22.0 MPa gives VAPOR.
  - The box T ∈ (647.0, 648.0) K × P ∈ [22.0, 22.2] MPa is refused `near_critical`.
  The generator must check that p_σ(647.0 K) > 22.0 MPa, that the critical point is inside the box, and that the band's metastable roots exist at 647.0 K. Alternative: label by density (LIQUID iff ρ > ρ_c), or answer metastable roots out to the spinodal (the pr_c1 L2 precedent). Reversible by: an amendment to the spec, since only the refusal set moves.
- DECISION: properties → per phase: `h`, `s`, `v`, `Z`, `cp`, `lnphi_H2O` (molar SI), with derivatives in T, P and `n_H2O`. The n-derivatives are exactly 0.0, because the properties are intensive for one component. Saturation: `Psat`(T) and `Tsat`(P), answered without a phase-stability check, and refused `no_saturation` outside [273.16 K, 647.0 K] (P outside [p_t, p_σ(647.0 K)]). `Psat` carries d/dT (Clausius–Clapeyron), and its d/dP is exactly 0.0. There is no `lnK`; that belongs to the binding package. Alternative: also `g`, `cv` and `w`. Reversible by: adding ids (additive).
- DECISION: flash → `TP` only. Outside the band it answers single-phase (vapour fraction 1.0 or 0.0; the other outlet is the zero stream). Inside the band it is refused `tp_flash_degenerate` (`unsupported`), because the split of a pure substance at fixed (T, P) is undetermined there. `near_critical` is refused. Alternative: refuse every flash, as pr-lib-v1 does. Reversible by: dropping `TP` from `flashes`.
- DECISION: density root → bracketed, safeguarded Newton. The vapour root lies in (0, ρ''(T)], extended by the band. The liquid root lies in [ρ'(T), 1250 kg/m³]. For T > 647.0 K the bracket is (0, 1250]. The generator asserts (∂p/∂ρ)_T > 0 on every bracket over a stated grid. Alternative: unbracketed Newton from an ideal-gas or IF97 seed. Reversible by: an amendment to the spec.
- DECISION: rights → IAPWS terms are `unresolved` (the site was refused). CoolProp is MIT, read from its dist metadata. `iapws` is GPL-3 and is used only as an executed comparison: nothing is copied or shipped. The coefficient file must not ship in a wheel until the IAPWS terms are read (L01-Q4 by analogy). Alternative: none. Reversible by: a rights row marked `vetted`.
