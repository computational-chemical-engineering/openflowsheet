Build-lane choices the design note (`docs/derivations/S08-design.md`, ADR 0048) left to the engineer. One line

## WO-1 (design note §5.5, §7 A12; S02 §8 item 6)

- DECISION W1-1: how the failure strings name `<bubble|dew>` while `saturation_errors` keeps §5.5's `-> dict[int, float]` → a private `_saturation_pairs` returns `(bubble, dew)` errors per `TWO_PHASE` stage; `saturation_errors` is the larger of the two (F4's definition of the error); `acceptance_failures` emits one `§8.6: TWO_PHASE stage <j>: <side> error <e> K` per side over `τ₆`, so a stage can carry two strings. Alternative: one string per stage naming the larger side, or a public pair-valued helper. Reversible by: the item-6 loop in `acceptance_failures` and `_saturation_pairs` (`column_solve.py`).
- DECISION W1-2: `<e>` is printed with `repr` (`{error!r}`), as every other §8 failure string in `acceptance_failures`; a non-`inside` band position prints `inf`. Alternative: `%g` or a fixed precision. Reversible by: one f-string.
- DECISION W1-3: cases §5.5 does not name → a `BandError` from `band_temperature` (a provider refusal or an exhausted bisection) and a phase of the stage with no positive flow are `inf`, i.e. item-6 failures, never a raise out of acceptance (the latter is already a `V_j, L_j > 0` failure; `band_temperature` would raise `ValueError` on it). Alternative: let `BandError` propagate, or skip the stage. Reversible by: the `try`/`any` guards in `_saturation_pairs`.
- DECISION W1-4: the band temperatures are evaluated under `DECLARATION_CONTEXT`, as `_admissibility` and §18.2's `_bubble_temperature` evaluate theirs. Alternative: a new context. Reversible by: one argument.
- DECISION W1-5: how A12 reaches F1's Stage-A state now that `solve_column(F1)` raises `AcceptanceDefectError` (item 6, until WO-3's Stage B) → the test wraps `column_solve.acceptance_failures` with a recorder that returns `()`, then calls the real function on the recorded arguments. F1's spec is inline (§6.2) until WO-G registers it. The interim `AcceptanceDefectError` on F1 is not pinned by a test; WO-3 replaces it with trigger (ii). Alternative: compile and call `solve_target` piecewise in the test. Reversible by: `_solve_recording` in `tests/test_s08_item6.py`.

## WO-2 (design note §5.2, §5.3, §7 A01–A04; `models/syn001/column_blocks.py`, `tests/test_s08_blocks.py`)

- DECISION W2-1: public names and signature the note leaves open → `sources(spec) -> Sources(liquid, vapor, fixed)` (sources as `(stage, kind)`, kinds `end`/`reflux`/`inlet`/`duty`, ordered ends, then inlets in `spec.inlets()` order, then intermediate duties by stage; fixed stages ascending), `candidates(spec) -> tuple[(a, c), ...]`, `block_signature(spec, (a, c)) -> tuple[Regime, ...]`, `block_endpoint(spec, provider, initial, (a, c), *, profile_shift, ratio_scale, max_sweeps) -> BlockEndpoint | CascadeFailure` (as `bubble_point_endpoint`), `BLOCK_ENDPOINT_ID = "s08-block-endpoint-v1"`. The builder accepts `(0, 0)` (A03) although §5.2 never generates it. Alternative: a candidate object carrying its sets. Reversible by: renames in `column_blocks.py`.
- DECISION W2-2: the energy solve's algorithm (§5.3 step 5 says only "safeguarded secant–bisection to `|ΔT| ≤ 1e-12` K") → secant from the domain ends; a bisection when the secant point leaves the open bracket or after two consecutive steps that do not halve it; stop on `g = 0`, `|T_new − T_prev| ≤ 1e-12`, or bracket width ≤ 1e-12; budget 200 evaluations (`MAX_ENERGY_EVALUATIONS`; the bracket halves at least every three evaluations, so < 150 suffice on a 160 K domain). Exhausting the budget refuses `block_energy_not_converged` (a reason string the note does not list; unreachable by construction). Alternative: Brent. Reversible by: `_energy_temperature`.
- DECISION W2-3: a provider refusal (status ≠ `ok`) of an enthalpy evaluation in a block stage's energy solve → refusal `block_energy_refused(<status>)` (a reason the note does not list). Alternative: fold it into `block_energy_outside_domain`, or raise. Reversible by: `_enthalpy`.
- DECISION W2-4: a `BandError` (provider refusal or exhausted bisection) inside the core sweeps or the condenser's bubble temperature propagates, as in §18.2's `bubble_point_endpoint`; only a band position other than `inside` refuses (`bubble_point_outside_domain`, also for step 7's condenser, which the note does not name). Alternative: map `BandError` to a refusal so that Stage B moves on. Reversible by: `_bubble`.
- DECISION W2-5: an empty core (`b = 0`) records `sweeps = 0`, `last_delta = 0.0`, `rho = {}` (no sweep runs). Alternative: `nan`/`None`. Reversible by: `_build`'s initial values.
- DECISION W2-6: step 9 calls `column_solve._admissibility` (the private helper through which S02 §8 applies `single_phase_admissible`), so the endpoint and acceptance run the identical test. Alternative: call `single_phase_admissible` directly. Reversible by: one call in `_build`.
- HAND-OFF to WO-3: `column_blocks` imports `stage_ratios`, `_admissibility`, `MAX_SWEEPS` and `SWEEP_TOLERANCE` from `column_solve` at module level, so `column_solve` must import `column_blocks` inside `solve_column` (function level) or at its end; a top-level `from ...column_blocks import ...` in `column_solve` makes an import cycle.
- Extra tests beyond A01–A04 (no new assertion ids): §5.2's sets on P3; `σ(a, c)` and its `ValueError`; P1's endpoint equals `ref.phase_case.P1`'s closed form and P2's equals §6.2's (`T_1 = 390 K`); a `block_energy_outside_domain` refusal (P1 at `Q_r* = 100 kW`).
