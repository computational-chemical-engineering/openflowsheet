# C11 — build decisions (column inverse specifications)

Append-only. One line per choice: `DECISION: <question> → <choice>. Alternative: <x>. Reversible by: <how>.`

### Specification (design lane `specifier`, 2026-10-22; `docs/derivations/S06-spec.md`, R-601 to R-607)

- DECISION: package id for C11 → **S06** (the next free S id after S05; R-565 / D1 Q6 want an S-letter id for scientific packages). Alternative: keep `C11` as the package id. Reversible by: renaming the spec, generator and evidence directory before the first manifest.
- DECISION: inverse kinds offered → `purity` (attribute `component`), `recovery` (attribute `component`), `temperature` (attribute `stage`), at either end slot; `mole_fraction`, `reflux_rate`, `boilup_rate`, `distillate_to_feed_ratio` stay `unsupported`. Alternative: also offer `mole_fraction` as an alias of `purity` (two ids for one row). Reversible by: an alias map in validation.
- DECISION: row form → every inverse slot row is `variable − parameter` (temperature `T_s − T*`; recovery `n_c − ν*` with `ν* = r*·F_c`; purity `u − π*` on a new `molar_flow` column `u = F·x_c` defined by `F·n_c − u·P` of kind `molar_flow_squared`), so ADR 0010 D2/D3 continue them unchanged and no kind, tolerance or ADR moves. Alternative: a `dimensionless` purity column with a `dimensionless` slot row (needs a row-kind ruling and, through K04's table, an ADR — S02 §17 item 5), or a ratio row `n_c − x*·P` with ADR 0010 D2 widened to ratio rows (an ADR change). Reversible by: ADR 0046 choosing either alternative; the generator's quotient rows do not change.
- DECISION: easy endpoint → S02 §18.2 unchanged; an inverse end takes the CMO stage ratio (φ⁰ at a total condenser) exactly like a duty end, and its slot is continued by edge 3 from the quantity's value at `x⁰`. Alternative: hold the inverse specification at the endpoint by adjusting the end's stage ratio inside the sweeps (no admissibility argument; a new algorithm). Reversible by: a later easy endpoint for inverse specifications (Q-S06-2).
- DECISION: temperature specifications → only on a stage that is two-phase at the answer; a target outside the stage's open band `(T_sat,lightest(P_s*), T_sat,heaviest(P_s*))` over the components present in the inlets is refused before evaluation; a converged answer with the specified stage single-phase is `unsupported(temperature_specification_on_single_phase_stage:<s>)`. Alternative: allow a single-phase specified stage (a superheating condenser or a non-boiling reboiler; degenerate columns). Reversible by: dropping I4 and the acceptance item.
- DECISION: static mass-balance refusal → exact product-split test in rational arithmetic (`infeasible_spec(mass_balance)`), plus `invalid_spec(redundant_specification)` when the specifications linear in the split are linearly dependent or two temperatures name one stage. Alternative: let infeasible splits fail in the solver (silence reads as a solver failure, not a refusal). Reversible by: removing I5/I6 (registered probes say which inputs move).
- DECISION: an inverse target the solve path does not reach → `inverse_specification_not_reached(<kind>:<end>)` on the answer with the last accepted λ and the quantity's value there; never an infeasibility claim. Alternative: map the solver outcome to `infeasible_spec` (false: U1 shows a regular root the path does not reach). Reversible by: a feasibility certificate in a later package.
- DECISION: multiplicity warning → no new code; C8's `multiple_steady_states_possible(duty_only)` keeps its rule (a set with an inverse specification is not duty-only). Alternative: warn on every set containing an inverse specification. Reversible by: one clause in `column_warnings` (Q-S06-1).
- DECISION: generator → `s06_reference.py` imports the S02 generator (independent of `src/`) for SYN-001, its column formulation and its endpoint, and adds quotient-form inverse rows and its own exact refusal test; four worker processes. Alternative: a stand-alone copy of S02's column code (duplicated, drifts). Reversible by: inlining the imported functions.

### WO-1 (build lane `opus-engineer`, 2026-10-22; specification, rows, refusals)

- DECISION: the `component` attribute's form → the component's name (`str`, one of `spec.components`), as every other column id uses names; the tests map the reference's index `i` to `COMPONENTS[i]` and index 3 to the undeclared name `"D"`. Alternative: an integer index. Reversible by: an index → name map at `validate`'s entry.
- DECISION: rule order within I1–I6 → each rule over the condenser end, then the reboiler end, before the next rule (the spec's "in this order"); the generator interleaves I1/I2 per end. Only a set violating two rules at different ends can tell them apart; no registered probe does. Alternative: the generator's per-end interleaving. Reversible by: reordering the two loops in `_inverse_refusal`.
- DECISION: `F` for the purity reference → `Σ_c F_c` summed in component order (`purity_reference`), as S06 §1 states; S02's S5 keeps `_feed_total` (`Σ_k Σ_c n_k,c`, inlet order). The two are equal with one inlet (every registered case) and may differ by roundings with several. Alternative: reuse `_feed_total` for `F`. Reversible by: one line in `purity_reference`.
- DECISION: exact arithmetic for I5/I6 → `Fraction(float)` of the binary64 inputs (S06 §5's words); the generator uses `Fraction(str)` of the decimal strings. Every registered probe gives the same answer either way. Alternative: decimal strings (not available to `validate`). Reversible by: none needed.
- DECISION: I5's rank → over every component (the table's rows as written, as the generator does); I6's split test → over the present components only (`t_c = 0` for an absent one). Alternative: rank over the present components (it differs only when two rows differ only in an absent component's coefficient). Reversible by: restricting `_rank`'s rows.
- DECISION: I6 with two independent rows and two or more free directions (four or more present components) → `ValueError` (misuse: SYN-001 declares three). The spec's three cases cover every SYN-001 set. Alternative: a general exact zonotope test. Reversible by: implementing it in `_split_feasible`.
- DECISION: the band → `saturation_temperature` (S06 §4's closed form) in `models/syn001/column.py`, with SYN-001's constants read from `thermo/syn001.py` (the module so far reached SYN-001 only through `PropertyProvider`). Alternative: bisection on the provider's `lnK` (`saturation_band.band_temperature` at β = 0 for a pure component). Reversible by: replacing the function body.
- DECISION: names → row builder `rows.scaled_definition_row(part, scale, scaled, whole)` (`F part − u whole`); families `COL-purity`, `COL-purity-definition`, `COL-recovery`, `COL-temperature` in `INVERSE_EQUATIONS`; public helpers `INVERSE_KINDS`, `COMPONENT_KINDS`, `component_feeds`, `purity_reference`, `inverse_parameter`, `specified_quantity`, `saturation_temperature`, `stage_band`, `product_flow_id`, `product_total_id`, `purity_flow_id`, `purity_reference_parameter`. `u` and its definition row are declared right after the end's slot row. Alternative: other names or a separate block after the stages. Reversible by: renaming (no frozen interface touched).
- DECISION: `spec_values` (`column_solve.py`) → gains one key per inverse end, `<end>_<kind>` (e.g. `condenser_purity`), from `specified_quantity` (§7.3's binary64 formula). Alternative: a separate `inverse_values` function. Reversible by: moving the loop.
- DECISION: `slot_column(spec, end, kind)` for an inverse kind → reads the attribute from the end's specification and refuses (`ValueError`) a `kind` that is not that end's. Alternative: a new signature with the attribute. Reversible by: a keyword argument.
- DECISION: S02's A02 probe `S2-not-offered` → names `mole_fraction` instead of `purity` (S06 §1 offers `purity`; the S2 rule stays tested; S06 A02 tests both ends). Alternative: none consistent with S06 §1. Reversible by: reverting the probe with S06.
- DECISION: A02's "provider stubbed to raise" → a provider that answers only while S01's R5 (`single_phase_admissible`, which precedes S02's and S06's rules and flashes the inlet) runs, plus `profile_initial`, `declared_rows`, `bubble_point_endpoint` and `solve_region` stubbed to raise, through `solve_column`. Alternative: a provider that always raises (then R5 raises on every probe). Reversible by: the test harness only.
- QUESTION: Q-S06-WO1-1 — the registered I3 probe (`ref.refusals.I3-absent`, feed (0.5, 0.5, 0) at M1's feed state 340 K, 1.04 bar, declared LIQUID) is above its bubble point (Σ z_i K_i ≈ 1.10), so S01's R5 answers first: measured `inadmissible_inlet(feed, LIQUID)`, not `infeasible_spec(absent_component:reboiler)`. The reference carries the feed flows, not the feed state, and the generator does not model R5. Kept as a strict xfail with that value; an unregistered companion test at 320 K (Σ z_i K_i ≈ 0.62) shows I3 itself. Proposed: the design lane registers the probe's feed temperature (e.g. 320 K) in the generator's probe and the spec's §9 text, and the xfail becomes a pass.
