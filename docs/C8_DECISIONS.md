# C8 — build decisions (duty-only multiplicity warning)

Append-only. One line per choice: `DECISION: <question> → <choice>. Alternative: <x>. Reversible by: <how>.`

DECISION: warning text → `multiple_steady_states_possible(duty_only)` (repo `code(detail)` grammar, constant `MULTIPLE_STEADY_STATES_WARNING` in `column.py`). Alternative: `multiple_steady_states_possible` without detail, or a detail naming the ends. Reversible by: editing the constant and the `WARNING` in `tests/test_c8_duty_only_warning.py`.
DECISION: duty-only ⇔ at least one end and every end specification of kind `duty` → a column with no ends gets no warning (R7's `all(...)` is vacuously true there, but nothing is specified and the answer is the dormant closed form). Alternative: warn on zero ends. Reversible by: dropping `ends and` in `column_warnings`.
DECISION: M3 and P1 (a single end, the reboiler, specified by duty) → warned, following Frank's rule "every duty-only column specification" and the R7 definition (every end a duty). Spec §18.1 item 3 registers the multiplicity only for the two-end `(duty, duty)` sets; whether a one-duty-end column can have several roots is not established. Alternative: warn only when two ends are both duties. Reversible by: requiring `len(ends) == 2` in `column_warnings`.
DECISION: failures → `CascadeFailure` gains `warnings: tuple[str, ...] = ()` (additive, default empty; no S01 construction or equality changes) and `solve_column` attaches the warning to every failure it returns for a duty-only spec (validate refusal, initializer, endpoint). Alternative: warnings on answers only. Reversible by: removing the `replace(..., warnings=warnings)` returns. `validate()` itself is unchanged and returns unwarned failures.
DECISION: `DormantAnswer` and `AcceptanceDefectError` carry no warning (no ends; an exception). Alternative: none considered. Reversible by: n/a.
NOTE (docs for the next design touch, S02 spec §14 "What this does not establish"): add: *a duty-only column specification (every end specification a duty) carries the warning `multiple_steady_states_possible(duty_only)` on its answer (Q-S02-4, C8); the warning discloses, and makes no root-selection claim.*
